# WMS PDA 交互定稿

- **批准日期：** 2026-09-21
- **状态：** 已经过用户批准（「本次 PDA 我觉得问题不大了，可以定稿了」）
- **范围：** 仓内 H5 作业端的交互与演示数据。不包含后端、独立部署、与 WMS 的正式接口。

本文件是 PDA 原型的定稿基线。此前各轮方案（岗位隔离、严格按原型、任务表、复制、质检样品标准、上架先选任务）以本文件为准；与旧稿冲突时以本文件为准。

## 产品边界

- PDA 是仓内作业端：到货、收货、质检、上架、配货、复核、盘点、移位。
- 各岗是不同的人。做完回到本岗下一单，不跳到下一岗位。
- WMS Web 是管理端。两边看同一套单据和唯一码，不共用页面。
- 主色与 Web 一致（`#006de6`），不用原型橙按钮。

## 定稿交互

- 待办是任务表，不是圆角卡片。上架先出待上架任务，点进去才扫唯一码和库位。
- 单号、SKU、唯一码、库位：点击文字即可复制，旁侧仅保留复制图标。
- 收货不放「退单 / 备货单」。质检不放「返单」。
- 「收货明细」是本单每一件唯一码（本次已扫 / 已收 / 未收），不是 SKU 汇总表。
- 质检页加宽。左侧三个唯一码框（合格 / 不合格 / 仓内维修），右侧尺码表和样衣图；点击图片或尺码表放大，不用「放大查看」文案。
- 质检、上架扫错码时，按真实情况提示：扫到的是 SKU、属于另一张收货单、尚未收货、已上架、已出库、或重复判定。不把这些都说成「不属于本单」。
- 错误用顶部红条。主按钮保持蓝色。

## 演示

- 入口：`wms/pda/index.html`，账号 `pda` / `pda123`
- 数据键：`wms_flow_v5`。页面只通过 `WMS_API` 访问数据。
