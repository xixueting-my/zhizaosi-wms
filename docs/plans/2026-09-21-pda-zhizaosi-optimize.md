# PDA 优化方案（织造司 + 列表对齐 + 库位查询 / 打印唯一码）

**批准日期：** 2026-09-21  
**状态：** 已经过用户批准（用户明确要求按截图优化点实施）

## 范围

1. **登录**：欢迎语改为「您好！ / 欢迎使用织造司PDA」
2. **选仓**：登录后进入「选择仓库」，仓库列表取自基础数据 `WMS_ORG`
3. **列表对齐**：PDA 内所有任务列表统一表格样式（列对齐、操作列、数字列）
4. **新增 · 库位查询**：扫 SKU 看各库位分布；扫唯一码看当前库位与状态
5. **新增 · 打印唯一码**：先扫并锁定库位，再每扫一次 SKU 生成并「打印」1 个唯一码（`SKU-序列号`）
