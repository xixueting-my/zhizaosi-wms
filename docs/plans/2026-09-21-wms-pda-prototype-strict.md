## 原型对照（必须对齐）

| 岗位 | 原型要点 |
| --- | --- |
| 到货确认 | 标题「到货确认」；「收货单号扫描」+ 扫码；扫后展示「订单信息」卡（单号/采购单/工厂/送货件数/发货时间）+ 待到货标签；确认后本岗下一单 |
| 收货 | 顶栏收货单号；扫「唯一码」；表：sku / 送货件数 / 已收件数 / 本次收货件数；底栏：收货明细、暂存、提交；关单红条；不足时弹窗「部分收货 / 收货完成」 |
| 质检 | 扫收货单号；三框：合格唯一码 / 不合格唯一码 / 仓内维修；SKU 列表进度；提交确认弹窗 |
| 上架 | 先扫唯一码，再扫库位（可锁定库位）；表：唯一码·SKU / 推荐·实际库位 / 状态；空态「准备扫描」；已上架红条 |
| 配货 | 配货详情：单号/状态/扫描进度；扫唯一码或 SKU；行卡含库位、标记缺货；底栏进度+提交；未扫完提交=主动缺货确认 |
| 复核 | 唯一码扫描；非待复核红条；确认/清空；订单明细 |
| 盘点 | 任务列表点「盘点」；先扫库位再扫 SKU/唯一码；盘前/实盘/差异 |
| 移位 | 移位下架：先扫下架库位 → 唯一码 → 再上架目标库位 → 提交下架 |
