# WMS 列表交互手感对齐（参考转化率统计页）

- **批准日期：** 2026-09-20
- **状态：** 已经过用户批准（「可以，直接改」）
- **参考：** `/Users/snow/Desktop/index_副本.html` 的即时筛选 / sticky / 微反馈
- **范围：** `wms/basic` 三页列表骨架（warehouse / params / strategy）

## 目标

在保留方案 1（浅色侧栏 + ERP 密度）的前提下，迁入参考页「跟手」交互，**不**搬 KPI / 日期看板 / 图表 / AI。

## 必须落地（P0–P2）

1. **筛选即时化**
   - 下拉、状态 sub-tab：`change` / 点击即筛
   - 文本框：300ms debounce + Enter 立即筛；「查询」保留为显式触发
2. **筛选条吸顶**
   - `.filter-bar`（及紧随的 `.sub-tabs` 若存在）在 Tab 内容区滚动时 sticky
3. **微反馈**
   - 输入聚焦环（浅蓝外发光）
   - 刷新按钮短暂 loading / disabled
   - 勾选行 `.is-selected` 高亮
   - 表头可排序（编码 / 名称 / 最后编辑等常用列）+ 轻量 hint

## 非目标

- 不改 mock 字段含义与抽屉表单校验逻辑
- 不引入 KPI、日期范围 pill、Chart、AI 抽屉
- 不改侧栏信息架构

## 验收

- 改库区类型 / 状态分段后无需点「查询」即可见结果
- 长列表滚动时筛选条仍可见
- 勾选库位后行背景变化；刷新有短暂反馈；表头点击可排序
