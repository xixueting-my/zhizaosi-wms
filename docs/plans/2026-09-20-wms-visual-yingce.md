- **批准日期：** 2026-09-20
- **状态：** 已经过用户批准（「按影策方向：灰画布 + 白卡片 + 中性选中 + 蓝只做 CTA，不要太多色彩」）
- **范围：** `wms/basic` 壳层与全局 CSS token；列表骨架（筛选→操作行→表→分页）与侧栏信息架构不变

## 必须落地

1. **画布：** 主区浅灰底（约 `#F6F7F9`）；表/筛选/内容块为白卡片 + 轻阴影  
2. **侧栏：** 保持浅色；选中改为中性灰圆角条，去掉大面积浅蓝底与右侧蓝竖线  
3. **主色：** 蓝仅用于主按钮（CTA）与文字链；导航/标签/计数尽量中性灰  
4. **少色彩：** 状态 tag 收敛为灰系为主，启用/停用仅保留必要语义色（绿/红弱化或线框）  
5. **圆角：** surface / 控件约 `8px`；不做创作页超大胶囊与大留白
