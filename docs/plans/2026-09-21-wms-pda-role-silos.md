# WMS PDA — 流水线分工（岗位独立）

- **批准日期：** 2026-09-21  
- **状态：** 已经过用户批准（明确：各模块不同人、流水线、不做「继续下一环节」）  
- **依据：** 用户需求截图 + 口头纠错  

---

## 1. 核心原则

| 原则 | 说明 |
| --- | --- |
| 岗位独立 | 到货 / 收货 / 质检 / 上架 / 配货 / 分拣 / 复核 = 不同工人 |
| 流水线 | 数据状态向下流转；**UI 禁止串岗跳转** |
| 本岗闭环 | 进本岗 → 扫单作业 → 完成 → **回本岗扫下一单** |
| 一屏一事 | 扫码 / 推荐库位 / 录数量 分屏 |

禁止文案与行为：`去质检`、`去上架`、`去复核`、`提交并去上架` 等。

---

## 2. 各岗边界

| 岗位 | 入口 | 完成时 |
| --- | --- | --- |
| 到货 | 扫送货单/运单 | 登记到货 → 继续本岗下一单 |
| 收货 | 扫已到货送货单 | 完成收货 → 回收货列表 |
| 质检 | 扫入库单 RK | 提交质检（数据侧生成上架任务）→ 回质检列表 |
| 上架 | 扫上架任务 SJ | 上完 → 回上架列表 |
| 配货 | 扫配货单 PH | 确认完成（数据交分拣/复核）→ 回配货列表 |
| 分拣 | 扫待分拣 PH | 完成 → 回分拣列表 |
| 复核 | 扫出库单/包裹 | 通过 → 回复核列表 |
