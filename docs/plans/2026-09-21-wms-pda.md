# WMS PDA（H5）产品方案

- **批准日期：** 2026-09-21
- **状态：** 已经过用户批准（在 review 稿上按纠错定稿）
- **纠错：**
  1. PDA 交互颜色与 Web / `erp-console-ui` 一致（主色 `#006de6`，画布 `#f2f3f7`，选中 `#dee9fb`）；**不用**原型里的橙主按钮方案
  2. Demo 之后要接真实数据上线，架构必须预留 API / 鉴权 / 租户头等接入口，禁止业务页写死 mock

---

## 1. 目标与边界

| 项 | 结论 |
| --- | --- |
| 形态 | H5：专业 PDA + 安卓手机浏览器可测 |
| 角色 | 仓内作业：到货 / 收货 / 质检 / 上架 / 配货 / 分拣 / 复核 / 盘点 |
| 与 Web | 同一业务状态机；Web 偏计划管理，PDA 偏扫码作业 |
| 视觉 | 与 Web 同 token，见 `erp-console-ui` |
| SaaS | 租户 → 登录 → 首页宫格 → 设置（切仓 / 退出） |
| 本期 | MockAdapter 驱动；HttpAdapter 骨架可切换 |
| 不做 | 真摄像头 SDK、蓝牙枪驱动、离线同步中间件（扫码框支持手动输入+回车模拟） |

### 已确认细节

- 盘点：PDA + 共享 mock；Web「库存盘点」仍灰置
- 库内移位：首页灰置「敬请期待」
- 质检：上 PDA（对齐原流程图）
- 租户：会话带 `tenantId`；Mock 可按租户隔离 key；Http 预留请求头
- 重逆向（作废 SO、取消波次）主 Web；PDA 轻逆向（反收货 / 撤回上架 / 撤回配货 / 反复核）

目录：`wms/pda/`

## 3. 与 Web 数据交互

共用领域规则（现 `wms/shared/js/flow.js`）。  
**页面不得直连 localStorage**；一律经 `WMS_API`。

```text
页面 → WMS_API（接口） → MockAdapter | HttpAdapter
                ↓
         Mock：flow.js + localStorage
         Http：REST（预留）
```

Web 模拟 MES/OMS/下发波次 ↔ PDA 作业，同一数据源时双向可见。

## 4. 接入真实数据的口子（上线预留）

### 4.1 配置

```js
window.WMS_CONFIG = {
  mode: "mock",           // "mock" | "api"
  apiBaseUrl: "",         // 例 https://api.example.com
  tenantHeader: "X-Tenant-Id",
  authHeader: "Authorization",
  tokenStorageKey: "wms_pda_token",
  tenantStorageKey: "wms_pda_tenant",
  warehouseStorageKey: "wms_pda_warehouse",
};
```

### 4.2 API 契约（Adapter 必须实现）

- SaaS：`listTenants` / `login` / `logout` / `me`
- 上下文：`setWarehouse` / `getWarehouse`
- 入库：与 flow 对齐的 `mesShip` 仅 Web；PDA：`arrive` / `receive` / `unreceive` / `startQc` / `submitQc` / `revertQc` / `confirmInbound` / `putaway` / `unputaway` + 列表查询
- 出库：`listPicks` / `advancePick` / `revertPick` / `shortagePick` / `resumePick` / `listCheckOrders` / `checkOrder` / `uncheckOrder`
- 盘点：`listStocktakes` / `startStocktake` / `countLine` / `submitStocktake`
- 通用：`getReceiving` 等只读查询

HttpAdapter：统一 `request(path, { method, body, query })`，自动带租户头与 Bearer Token；401 跳登录。

### 4.3 切换方式

改 `WMS_CONFIG.mode = "api"` 并填 `apiBaseUrl`，无需改页面。  
Mock 与 Http **方法名、参数、返回 `{ ok, message, data }` 形状一致**。

## 7. 验收

1. 手机打开 PDA：租户 → 登录 → 首页  
2. Web 发货后 PDA 可到货→收货→质检→上架，Web 同步  
3. Web 下发波次后 PDA 配货/分拣→复核，Web 同步  
4. 盘点可提交  
5. `mode` 切到 `api` 时仅 Adapter 换实现，页面无 mock 分支  
6. 颜色与 Web 一致（蓝主按钮，无橙 CTA）
