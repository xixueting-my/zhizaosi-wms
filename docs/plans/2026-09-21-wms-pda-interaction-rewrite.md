2. **扫完自动下一步**，输入框清空回焦（适配扫码枪回车）  
3. **出错大弹窗** → 清空重扫，不跳走丢单  
4. **状态全部中文**，禁止英文枚举直接展示

## 主路径节奏

| 模块 | 节奏 |
| --- | --- |
| 到货 | 扫单号 → 成功 → 同厂下一单 / 去收货 |
| 收货 | 扫单 → 明细+顶栏扫物料 → 全屏数量 → 回明细 → 完结/部分原因 → 质检 |
| 质检 | 扫 RK → 填数 → 提交并确认入库 → 上架 |
| 上架 | 扫任务 → 扫物料 → **大字推荐库位** → 扫库位 → 数量 |
| 配货 | 扫单 → **大字库位+拿什么拿几件** → 扫库位 → 扫物料 → 数量 |
| 复核 | 扫出库单 → **大号已核/应核** → 逐件扫 |
| 盘点 | 任务 → 行列表 → 扫物料核对 → 数量暂存 → 提交 |

内存步骤机（`session.step`），不再靠 URL `phase` 拼装。
