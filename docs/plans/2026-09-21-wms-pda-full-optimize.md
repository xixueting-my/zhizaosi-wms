# WMS PDA 全量作业优化（万人工商业版）

- **批准日期：** 2026-09-21
- **状态：** 已经过用户批准（明确要求本期全部做、不按优先级分期）
- **背景：** 面向后续上万仓内工人的超大型商业产品；对照需求截图补齐全部交互缺口

---

## 1. 范围（本期全部）

| 能力 | 说明 |
| --- | --- |
| 统一扫码态 | 「请扫描或输入」+ 手动输入提示 + 确认/回车 |
| 大弹窗错误 | 条码不符 / 超收超拣 / 库位顺序错误等阻断式提示 |
| 收货多明细行 | 按行扫物料 → 大数字键盘录数量 → 进度条 |
| 到货串联 | 到货成功可建议同厂下一单 |
| 边收边检 | 收货完成后引导质检；质检后可确认入库进上架 |
| 上架推荐库位 | 扫物料 → 展示推荐库位 → 扫库位（可偏离确认）→ 数量 |
| 配货库位引导 | 当前应拣库位大字 + 扫库位 → 扫物料 → 数量 + 总进度 |
| 复核逐件 | 扫 SKU 累加已核数，到齐自动通过；支持包裹码一次通过 |
| 盘点暂存/提交 | 行级暂存与任务暂存分离；未盘齐不可提交 |
| 异常反馈 | 首页入口 + 作业页入口 |
| 网络态 | 顶栏离线提示 + 重试；提交前校验在线 |
| 空状态 | 统一插画式空列表 |
| 数字键盘 | 收货/上架/配货/盘点大键盘 |
| 数据模型 v2 | `wms_flow_v2`：lines / recommend_location / pick lines / checked_qty / exceptions |
| API 口子 | Mock/Http 同步新增 `receiveLine` / `putawayDo` / `pickLine` / `checkScan` / `submitException` / `saveStocktakeDraft` 等 |
