# 织造司作业台与手持 UI

新项目按本规范做两套界面，不要做成营销站，也不要混用两套操作列。

- **后台作业台**：给仓管看单据。高密度列表。
- **手持 PDA**：给现场扫码。桌面预览必须像一台手机。

开工前先读 [PROMPT.md](PROMPT.md)。用户把那段 prompt 贴进新对话时，按本 skill 执行。

## 共用

| 角色 | 值 |
| --- | --- |
| 主色 | `#006de6` |
| 主色悬停 | `#1a7ceb` |
| 选中底 / 浅蓝 | `#dee9fb` |
| 画布 | `#f2f3f7` |
| 卡片 | `#ffffff` |
| 正文 | `#333333` |
| 次文字 | `#666666` |
| 辅助 | `#8c8c8c` |
| 边框 | `#e8e8e8`（PDA）/ `#f0f0f0`（后台分割） |
| 危险 | `#e85a6b` |
| 成功 | `#389e0d` |
| 警告 | `#d48806` |
| 字体 | `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif` |

禁止紫渐变、奶油风、Ant Design 默认蓝 `#1890ff`、大留白英雄区、厚阴影卡片墙。

文案用简体中文。错误直接写给操作的人看，例如「这件还没有收货，不能质检」。

## 后台作业台

1. 白侧栏、白顶栏、灰画布。筛选、页签、表格各自白卡，中间留缝。禁止整页一张大白卡。
2. 侧栏选中：底 `#dee9fb`，字和图标 `#006de6`。页内 Tab：蓝字 + 2px 蓝下划线。不要右侧粗蓝竖线。
3. 查询、新增：实心蓝底白字。重置：白底灰边。
4. **操作列是 12px 文字链**，不是实心按钮。常规蓝 `#006de6`，取消 / 删除 / 停用红 `#e85a6b`。
5. 密度：正文 12px，行高约 36px，控件高 28px，圆角 4px。图标细线，描边约 1.25，跟文字同色。
6. 数字用 `tabular-nums`。下拉改完即筛。文本搜索保留查询和重置。
7. 工人在手持上完成的动作（到货确认、逐件收货、逐件质检、逐件上架、拣货完成、缺货），后台不要再做一套同样的主按钮。后台显示状态，并写明「由 PDA 回写」。

列表骨架：

```
[白侧栏] [白顶栏 · 面包屑]
         [灰画布]
           [白卡 · 页签]
           [白卡 · 筛选：查询实心蓝 / 重置白边]
           [白卡 · 表]
             [操作行]
             [表 · 操作列文字链]
             [分页 · 当前页实心蓝]
```

## 手持 PDA

桌面宽屏（视口宽于 420px）把界面放进手机里：

- 外框宽 390px、高不超过 844px，黑底、圆角、浅阴影。
- 屏内顶部状态栏：时间、信号、电量，底色用主色。
- 屏内底部操作栏：返回、主页、最近任务。返回触发页内返回；主页回首页。
- 作业底栏（提交、确认）贴在系统操作栏上方，相对手机屏幕定位。禁止 `position: fixed` 到浏览器窗口，否则按钮会跑到手机外面。
- 页面在手机屏幕内部滚动。`overflow: hidden` 只放在手机外壳上。外壳里的内容区必须能滚动。
- 视口窄于或等于 420px 时去掉黑外框，状态栏和底部操作栏仍保留。

顶栏：返回、标题、测试标记、仓库名、账号。仓库名过长可省略。标题和账号不能裁成半个字。

扫码：标签在上，输入框内右侧放「扫码」。提交失败用红条，成功用短时 toast。

**操作列一律实心蓝按钮**，禁止做成纯文字链。按钮 `min-width: 0`，高度约 28px，按文字宽度留白。列宽按内容撑开，390px 下「上架」「去确认」「去配货」「打印唯一码」必须完整可见。

数据点击即复制：单号、SKU、唯一码、库位、工厂、数量。点击后提示「已复制」。不要只在部分列放复制图标。操作按钮、输入框不触发复制。

列表表格锁在屏幕宽度内：

- 操作列 `width: 1%`、`white-space: nowrap`、`max-width: none`，不裁切。
- 其余列可省略号。长 SKU 允许换行。
- 禁止 `table-layout: fixed` 再把操作列写成约 56px，同时给按钮 `min-width: 96px`。这会把按钮切成一个字。

多块内容不要用两列网格把主栏挤成 0 宽。宽表放在表格容器里横向滚动，页面本身不横向撑破手机。

静态 HTML 改完 CSS 或 JS 后，给文件地址加上新的 `?v=`，避免浏览器继续用旧文件。

## 交付前自检

后台：

- [ ] 画布是 `#f2f3f7`，筛选和表格分成白卡
- [ ] 主色是 `#006de6`
- [ ] 侧栏选中底是 `#dee9fb`
- [ ] 查询是实心蓝，重置是白边
- [ ] 操作列是 12px 文字链，危险操作为红

手持：

- [ ] 宽屏能看到黑外框、状态栏、底部返回 / 主页 / 最近任务
- [ ] 390px 下每个操作按钮的文字完整
- [ ] 顶栏账号没有被裁切
- [ ] 主内容区高度不为 0，列表能滚，按钮不被外壳切掉
- [ ] 点击单号或 SKU 会复制
- [ ] 作业按钮在手机底栏上方，不在浏览器窗口最底部外面

## 不要再犯

| 做过的错 | 正确做法 |
| --- | --- |
| 桌面上一块没有外框的长页面 | 宽屏套手机轮廓 |
| 手机框 `overflow: hidden` 且内部不滚动 | 外壳隐藏溢出，内容区滚动 |
| 两列网格在窄屏把左栏压成 0 | 手持单列；宽表自己横向滚动 |
| PDA 有的操作是按钮、有的是文字 | PDA 操作全部实心按钮 |
| 只有部分单元格有复制图标 | 数据点击即复制 |
| 底栏相对浏览器固定 | 底栏相对手机屏幕 |
| 后台和手持都做同一个扫码主按钮 | 扫码在手持，后台只看状态 |
