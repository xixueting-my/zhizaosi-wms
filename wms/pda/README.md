# WMS PDA

严格按需求原型实现的仓内 H5。各岗流水线独立，**不做串岗跳转**。

## 打开

`wms/pda/index.html` → 租户 → 登录（织造司）→ 选择仓库 → 首页

设置里可「重置演示数据」（`wms_flow_v9`），或把数据来源改成「对接 WMS」并填写后台根地址。接口见 `docs/plans/2026-09-21-wms-pda-api.md`。

## 编码规则

- **SKU** = `站点名称||SPU||色系||尺码`，例 `yours||FUZ1663||DustyLavender||XS`
- **唯一码** = `SKU-序列号`，例 `yours||FUZ1663||DustyLavender||XS-1`  
  详见 `docs/plans/2026-09-21-sku-uc-rules.md`

## 新增岗位

| 岗位 | 说明 |
| --- | --- |
| 库位查询 | 扫 SKU 看库位分布；扫唯一码看库位与状态 |
| 打印唯一码 | 先锁库位，再每扫一次 SKU 生成并打印 1 个唯一码 |

## 演示单号（重置后）

| 岗位 | 建议扫 |
| --- | --- |
| 到货确认 | `SO2609190001` |
| 收货 | 同上（先到货）→ 扫唯一码如 `yours\|\|FUZ1663\|\|DustyLavender\|\|XS-1` |
| 质检 | 收货完成后扫收货单号，再扫合格唯一码 |
| 上架 | 合格唯一码 → 库位 |
| 配货 | `PH2606240015` → SKU/唯一码 |
| 复核 | 出库单或唯一码 |
| 盘点 | `ST2608110003` |
| 移位 | 下架库位 → 唯一码 → 目标库位 |
| 库位查询 | 任意已上架唯一码，或库存明细中的 SKU |
| 打印唯一码 | 库位如 `YOURS-01-01` → SKU `yours\|\|FUZ1001\|\|Black\|\|M` |

## 原型对齐要点

- 顶栏：返回 + 标题 + 测试 + 仓库 + 用户  
- 扫码框右侧「扫码」  
- 收货：唯一码 + 表（送货/已收/本次）+ 暂存/提交  
- 质检：合格/不合格/维修三框  
- 上架：唯一码→库位，可锁定库位  
- 错误：顶部红条  

详见 `docs/plans/2026-09-21-wms-pda-prototype-strict.md`
